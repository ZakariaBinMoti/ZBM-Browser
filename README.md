## 🚀 Download & Installation

### Option 1: Download from GitHub Releases (Recommended for Everyone)
1. Head over to the **[GitHub Releases Page](https://github.com/ZakariaBinMoti/ZBM-Browser/releases)**.
2. Download **`ZBM-Browser-Setup-x.x.x.exe`** (Standard Installer) or **`ZBM-Browser-Portable-x.x.x.exe`** (No installation needed).
3. Run the installer. It will automatically create your **Start Menu** entry and **Desktop Shortcut**!

### Option 2: Run from Local Source / Portable Scripts
1. **One-Click Local Installer:** Double-click **`Install_ZBM_Browser.bat`**
   - Automatically registers **ZBM Browser** in your Windows Start Menu and creates a Desktop Shortcut.
2. **One-Click Launch:** Double-click **`Launch_ZBM_Browser.bat`** (or `Launch_ZBM_Browser.vbs` for silent background launch).

## 🔄 Seamless Auto-Updates

ZBM Browser features built-in automatic update detection powered directly by GitHub Releases:
- **Automatic Background Checks:** Whenever the browser is launched, it checks GitHub for new releases.
- **In-App Check for Updates:** Open the hamburger menu `☰` and click **"Check for Updates"** anytime.
- **One-Click Upgrade:** When a new version is published to GitHub, the browser downloads it in the background and displays a clean update notification with a **"Restart to Update"** button.

## 🌐 Full Modern Browser Features

- **Multi-Tab Architecture:** Open, switch, and close multiple tabs smoothly with `Ctrl + T` and `Ctrl + W`.
- **Split-Screen Dual View (`Alt + 2`):** Watch video on one side while coding, reading docs, or taking notes on the other side with simultaneous side-by-side tabs!
- **Find in Page (`Ctrl + F`):** High-speed in-page search with real-time match counter, next/previous highlights, and keyboard navigation.
- **1-Click Crisp Video Frame Capture (`Ctrl + Shift + S`):** Captures high-res video frames without player UI clutter, saving automatically to Downloads and copying to system clipboard.
- **Page Zoom Controller (`Ctrl + +` / `Ctrl + -` / `Ctrl + 0`):** Zoom in, zoom out, or reset page zoom from 40% to 250% with animated zoom indicators.
- **Private / Incognito Tabs (`Ctrl + Shift + N`):** Isolated in-memory browsing partitions that discard all cookies and history upon closing.
- **RAM Eco Saver Engine (`Alt + E`):** Intelligent tab hibernation that puts background tabs to sleep, freeing 60-80% memory for maximum RAM efficiency. Sleeping tabs wake instantly on click!
- **Distraction-Free Reader Mode (`Alt + R`):** Strips annoying banners, popups, and clutter from articles and documentation, formatting them in beautiful, clean serif typography.
- **Native Picture-in-Picture (`Alt + P`):** Pops video out into Windows' floating native PiP player so you can multitask freely across any app.
- **Clean URL Copy:** One-click button in address bar to strip tracking parameters (`utm_*`, `fbclid`, `gclid`, `si`) and copy clean short links.
- **Smart Bookmarks & Quick Star (`Ctrl + D`):** Star any page directly from the Omnibox to save it to your bookmarks bar.
- **Browsing History Drawer (`Ctrl + H`):** Slide-out drawer with search filter, timestamps, and 1-click restore.
- **Privacy Cache & Data Clearer (`Ctrl + Shift + Del`):** Purge cache, cookies, and browsing data on demand.
- **Theme Accent Color Switcher:** Choose from 5 sleek glassmorphic themes (Cyber Cyan, Emerald, Violet Glow, Sunset Gold, Crimson Red).
- **Permanent Login Persistence:**
  - Dedicated persistent profile storage (`%APPDATA%\ZBM-Browser-Data`).
  - Google Account, YouTube, and other websites stay signed in permanently across restarts.
  - Firefox Desktop User-Agent with stripped Client Hints guarantees zero "unsupported browser" blocks.
- **Smart Omnibox Search Shortcuts:**
  - Type `yt [query]` → Searches directly on YouTube
  - Type `g [query]` → Searches directly on Google
  - Type `ai [query]` → Sends query directly to ChatGPT
  - Type `wiki [query]` → Searches Wikipedia
  - Type `gh [query]` → Searches GitHub repositories
  - Type `r [query]` → Opens subreddit or Reddit search
- **Auto Session Restore:**
  - Automatically remembers and restores all previously open tabs on restart.
- **Universal Ad & Tracker Shield:**
  - Built-in network-level blocking of popups, banner ads, tracking scripts, and video ads.
- **Universal Force Dark Mode (`Alt + Shift + D`):**
  - Converts bright white websites into an eye-friendly dark theme without inverting media or images.
- **Native Downloads Manager:**
  - Real-time download progress tracking with speed, progress bar, and "Show in folder" actions.

## 🛡️ Advanced Privacy & Workplace Stealth Suite

### 1. 🎥 Meeting Invisibility Shield (`Alt + S`)
- When enabled, the browser becomes **100% INVISIBLE in Zoom, Microsoft Teams, Google Meet, Discord, and Screen Recordings** using Windows `WDA_EXCLUDEFROMCAPTURE` API!
- You can watch or read whatever you want on your screen, while colleagues in the meeting only see the desktop or spreadsheet behind your browser window!

### 2. 🎬 Crystal-Clear Stealth Video Focus (`Alt + V` or `F`)
- Completely strips page clutter, recommendations, comments, and headers.
- **Zero Blurriness:** Completely disables YouTube's ambient canvas and renders native HD video with `object-fit: contain`.
- Floating auto-hiding HUD with timeline scrubber, volume booster, and speed selector.

### 3. 💼 Multi-Decoy Camouflage Suite (`Alt + D` or `F2`)
Instant one-click morphing into 4 authentic workplace screens:
1. **Betopia ERP** - Sales Orders, billing status, and corporate client records.
2. **Microsoft Excel** - Q4 Financial Model, formulas (`=SUM(...)`), and EBITDA variance table.
3. **VS Code** - Cloud API auth service code editor with syntax highlighting.
4. **Microsoft Teams / Slack** - Corporate engineering channel and server deployment chat.

### 4. 🔊 Audio Booster (up to 300%)
- Built-in Web Audio API gain amplifier to boost quiet videos and podcasts from 100% to 150%, 200%, or 300%.

### 5. 🎚️ Dynamic Opacity Engine
- **Slider & Hotkeys:** `[` to reduce opacity, `]` to increase opacity (or `Alt + Up` / `Alt + Down`).
- **CCTV Camouflage:** Set opacity to **30% - 40%**. Text from your office work shows right through the window.

### 6. 🚨 Panic "Boss Key" (`Alt + X` or `Esc`)
- System-wide global hotkey that **instantly hides the window** and **mutes all audio** in milliseconds.

### 7. 👻 Ghost Mode / Click-Through (`Alt + C`)
- Mouse clicks pass directly through the browser window to applications underneath.
